# QuickBite Delivery App

A lightweight food delivery web app built with HTML, CSS, and JavaScript.

## Features

- Browse popular food dishes
- Search and filter menu items by category
- Add items to a cart and see total pricing
- Place order and watch a live delivery status tracker

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080` in your browser.
